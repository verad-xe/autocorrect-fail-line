One line, a funny autocorrect fail: an anniversary text in which autocorrect turns butterflies into butter knives — "Happy anniversary, honey! Six years of marriage and I still get butter knives every time you walk into the room". It reads as a real autocorrect slip (autocorrect famously splits compound words apart), the intended word is obvious from the romantic context, and the wrong words are specific and surprising. Running `main.py` writes exactly that one line, and nothing else, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
